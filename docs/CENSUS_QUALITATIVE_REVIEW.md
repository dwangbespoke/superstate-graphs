# Post-formation census assignment review

This is a purposive qualitative review by a coding agent of **14 saved full-prefix assignments**, not a human study, gold-label dataset, random sample, or estimate of population accuracy. Formation was already frozen. No findings enter optimization, routing, completion, or task generation. No heldout evaluator outcomes were consulted. The sample includes prefixes from all three splits solely for this post-formation inspection.

The reviewed candidate is `a24da5e97a2156d80947ed79268f433d5456d587b00a97d338cd804bc85390f3`. Its state specification is unchanged from the seed. This review concerns assignments to that selected specification, before any added completion states or reconstructed edge contracts. The [frozen graph review](FROZEN_GRAPH_REVIEW.md) separately examines definition and edge-contract consistency.

## Frozen sample and evidence

The snapshot at **2026-09-17 17:52:52 UTC** contained 1,023 completed rollout assignments and 37,093 histories. All 1,023 available h0 prefixes were assigned `initial_task_context`; 411 later prefixes also received that label. These are incomplete-census descriptive counts. A later step number alone is **not** evidence of an invalid assignment.

Selection preceded reading the selected histories: choose the shortest complete prefix, breaking ties by history ID, for h0 in each split; include one h0 per alternative assigned state if present (none); choose the two shortest later prefixes assigned initial and the unique maximum-step later initial prefix; choose the shortest prefix in each of eight predeclared occupied states (`model_files_created`, `model_execution_in_progress`, `model_execution_failed`, `data_verified`, `model_rebuilt_with_fix`, `dbt_debug_verified`, `duckdb_cli_unavailable`, `empty_result_set`). This deliberately favors readable short histories and one late-stage extreme; it is not representative sampling.

A private audit manifest preserves the complete evidence, prefix SHA-256 values, exact state definitions and exclusions, selection strata, and assessments for all 14 cases. It is not included in the public repository. Prefix hashes were checked; the public history IDs below identify the reviewed boundaries. Router explanations are inspected as model outputs; factual findings below come from actual actions and tool observations, paraphrased here without publishing the source prefixes. For h_k, the latest completed group is group k−1; h0 has no executed group.

## Implication and next-version ideas

The documented conflicts show that complete input histories and non-null coverage do not ensure adherence to a state's evidence requirements. In particular, an observed directory/project can still route to initial, and edits can route to a state requiring execution. They also caution against interpreting every member of a node as satisfying a shared edge prerequisite. This sample does not measure how frequent those failures are, validate or invalidate the entire graph, or establish downstream task failure.

Possible **future-version** repairs, not applied or evaluated in this run: make initial membership distinguish query-supplied facts, pending inspections, and verified exploration; distinguish an existing/read artifact, an edit, a submitted rebuild, and observed rebuild completion; make verification labels name the actual checked properties instead of implying all requirements; and require the router's evidence to support required predicates and address explicit exclusions. These are targeted responses to the documented cases, not evidence of superiority for a revised method. Any revised system needs a new frozen evaluation, and this inspected material must not be presented as untouched test evidence for that revision.
